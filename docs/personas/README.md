# 👥 Персона — Card Battle тоглоомын хэрэглэгчийн дүрүүд

---

## Персона 1: Түмэнжаргал

🎓 IT оюутан, карт тоглоомын фанат

| Шинж | Утга |
|------|------|
| Нэр | Түмэнжаргал ("Түмэн") |
| Нас | 21 |
| Мэргэжил | Програм хангамжийн инженерийн 3-р курс оюутан |
| Тоглоомын туршлага | Hearthstone 2 жил, Slay the Spire 200+ цаг, Magic: The Gathering Arena, D&D |
| Төхөөрөмж | Laptop (Linux terminal) + Android гар утас |
| Хэзээ тоглодог | Хичээл хоорондох 10-20 мин завсарлага, оройн цай уух үед |

**Motivation (юу хүсэж байна вэ?):**
- Хичээлийн завсарлагаанд богино тоглоом (5-15 мин)
- Стратегийн гүнзгий бодлого шаардах карт комбо олох сонирхол
- AI-тай дахин дахин тоглож тактик сайжруулах

**Frustration (юу бухимдуулна вэ?):**
- Маш удаан tutorial — шууд тоглож эхлэхийг хүсдэг
- Тоглоомоо хадгалж болохгүй бол завсарлага дуусахад алдагдана
- "Рандом" шиг мэдрэгдэх AI — бодолгүй тоглодог бол сонирхолгүй

**Таны тоглоом түүнд яагаад таалагдах вэ?**
- 20 картын багцад 4 төрлийн карт (Attack, Heal, Buff, Creature) = стратегийн олон хувилбар
- AI тэргүүлэх дарааллаар тоглодог (HP бага бол heal, buff+attack combo) — challenge байна
- Save/load байгаа — хичээл эхлэхэд Ctrl+C дарчихаад дараа нь үргэлжлүүлнэ

**Таны тоглоом түүнийг яагаад бухимдуулж магадгүй вэ?**
- ASCII хязгаарлалт — Hearthstone-ийн гоё анимацитай харьцуулбал visual бага
- 20 карт → хэдэн тоглоомын дараа бүх карт танил болж, шинэлэг мэдрэмж алга болно
- Multiplayer байхгүй — найзтайгаа тоглох боломжгүй
- Creature-ийн interact бага (creature vs creature дайралт байхгүй)

## Персона 2: Сарнай

👩‍👦 Ажилтай ээж, хүүтэйгээ хамт цаг өнгөрөөхийг хүсдэг

| Шинж | Утга |
|------|------|
| Нэр | Сарнай |
| Нас | 38 |
| Мэргэжил | Нягтлан бодогч, оройн ээлжинд ажилладаг |
| Тоглоомын туршлага | Mobile casual (Candy Crush, Among Us, Roblox хүүтэйгээ), тоглоомын карт цуглуулж байсан |
| Төхөөрөмж | Ажлын Windows laptop |
| Хэзээ тоглодог | Оройн 8-9 цагт хүүтэйгээ (11 настай) хамт суугаад |

**Motivation (юу хүсэж байна вэ?):**
- Хүүтэйгээ хамт цагийг өнгөрөөх
- Хэтэрхий хүч шаардагдсан биш, зугаатай тоглоом
- Ойлгоход хялбар дүрэм — 5 минутад суралцах
- Хүүдээ programming-ийн ертөнцийг танилцуулах (terminal тоглоом = "кодоор хийсэн юм")

**Frustration (юу бухимдуулна вэ?):**
- Англи хэлний мессеж олон бол ойлгохгүй
- "Invalid input" гэхэд юу хийхээ мэдэхгүй
- Тоглоом хэтэрхий урт (30 мин+) бол хүү уйдна
- Суулгахад хэцүү — Java, compile гэх мэт алхмууд

**Таны тоглоом түүнд яагаад таалагдах вэ?**
- Монгол хэлтэй error message + зааварчилгаа
- Emoji + карт нэр = хүүд нь гоё харагдана ("🐲 Dragon!!" гэж баярлана)
- HP bar визуал (████░░) тоо тоолохгүйгээр хэн хожиж байгаа нь тодорхой
- Тоглоом богино (10-15 ээлж ≈ 5-8 мин) — унтахын өмнө яг тохирно

**Таны тоглоом түүнд яагаад бухимдуулж магадгүй вэ?**
- "-1 оруул" гэдэг ойлгомжгүй — "дуусгах" button-тай бол дээр
- Мана систем нарийн — яагаад тоглож болохгүй байгааг ойлгохоос өмнө бухимдана
- Terminal-ийн ерөнхий харагдах байдал хүүхдэд "хуучин" мэт санагдаж магадгүй
- BuffCard-ийн үр дүнг шууд харахгүй — "энэ юу хийсэн юм?" асуулт гарна
