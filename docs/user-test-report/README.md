## Findings

### 🔴 Блокер (амжилтгүй болгосон / урт зогсоосон зүйл)

#### 1. Ээлж дуусгах арга ойлгогдсонгүй (3/3 хүн)
- **Байдал:** Тоглогч бүх картаа тоглочихсоны дараа "одоо юу оруулах вэ?" гэж бухимдсан
- **Оюунаа:** "Минус нэг гэж юу вэ? Тэг оруулъя" → error → "Тоо оруулна уу" → бухимдсан
- **Тэмүүлэн:** "Ээлж дуусгах" гэдгийг 30 секунд хайсан, prompt-ыг уншаагүй
- **Ганзориг:** Мэдсэн ч "UX-ийн хувьд '-1' гэж хачин юм" гэж тэмдэглэсэн
- **Ноцтой байдал:** 🔴 3/3 хүн зогссон

#### 2. BuffCard-ийн үр дүн ойлгогдсонгүй (2/3 хүн)
- **Байдал:** "⚔️ Sharpened Blade" тоглосны дараа юу өөрчлөгдсөнийг мэдрээгүй
- **Оюунаа:** Buff тоглоод дараагийн ээлжид AttackCard тоглоход "энэ юу нь нэмэгдсэн юм?" гэсэн
- **Тэмүүлэн:** "Энэ карт юу хийсэн юм? Ямар ч юм болсонгүй" гэсэн
- **Ганзориг:** Buff идэвхтэй мөрийг олж харсан — "ааа энэ дараагийнхдаа нэмэгднэ гэсэн үг"
- **Ноцтой байдал:** 🔴 2/3 хүн ойлгоогүй

#### 3. Мана систем тайлбаргүй (2/3 хүн)
- **Байдал:** Эхний 2 ээлжид мана бага (3-4) байхад "Мана: 7" картыг тоглох гэсэн
- **Оюунаа:** "Яагаад тоглож болохгүй юм?" → error → "Мана хүрэлцэхгүй" → "Мана гэж юу вэ?"
- **Тэмүүлэн:** "Мана гэдэг нь энерги шүү дээ" гэж өөрөө ойлгосон (Minecraft XP-тэй адилтгасан)
- **Ноцтой байдал:** 🟡 Ойлгосны дараа OK

## Хийсэн 3 сайжруулалт

### Сайжруулалт 1: Ээлж дуусгах удирдамж тодорхой болгосон

**Өмнө:**
```
🃏 Гартаа буй картууд:
  [0] 🔥 Blazing Fireball (Мана: 3) — 4 хохирол [COMMON]
  [1] 🍃 Morning Dew (Мана: 2) — 4 HP эдгэрнэ [COMMON]
Тоглох картын дугаарыг оруулна уу:
```

**Дараа:**
```
🃏 Гартаа буй картууд:
  [0] 🔥 Blazing Fireball (Мана: 3) — 4 хохирол [COMMON]
  [1] 🍃 Morning Dew (Мана: 2) — 4 HP эдгэрнэ [COMMON]
  [-1] Ээлж дуусгах
Тоглох картын дугаарыг оруулна уу (-1 дарвал ээлж дуусах):
```

**Үр дүн:** `[-1] Ээлж дуусгах` гэсэн тусгай мөр нэмснээр 3/3 хүн дараагийн тестэд шууд ойлгосон.

---

### Сайжруулалт 2: Buff идэвхтэй үед feedback мөр нэмсэн

**Өмнө:** Buff тоглоход зөвхөн "⚔️ ... +2 хохирол нэмэгдлээ!" гэсэн мессеж гарч, дараагийн ээлжид юу ч харагдахгүй.

**Дараа:** Player-ийн мэдээллийн мөрөнд buff идэвхтэй үед шар өнгөтэй мөр нэмэгдсэн:
```
Баатар          HP: ████████████████████ 30/30   Мана: ◆◆◆◆◇ 4/5
  ⚔️  Buff идэвхтэй: +2 хохирол дараагийн довтолгоонд
```

**Үр дүн:** Тоглогч buff-ийн үр дүнг ээлж бүрт хардаг болсон. Дахин тестэд 3/3 хүн "аа дараагийн attack-д нэмэгдэнэ гэсэн үг" гэж шууд ойлгосон.

---

### Сайжруулалт 3: Мана хүрэлцэхгүй үед тодорхой тайлбар

**Өмнө:** Зүгээр л `InsufficientManaException` throw хийгдэж, дотоод message нь "Мана хүрэлцэхгүй" гэдэг.

**Дараа:** Error handler нь эелдэг мессежийг хэвлэнэ:
```
  ✗ Мана хүрэлцэхгүй ээ, өөр карт сонгоно уу.
```
+ Exception мессеж нь тодорхой тоо өгнө: `"Мана хүрэлцэхгүй (7 шаардлагатай, 3 байна)."`

**Үр дүн:** Оюунаа "аа 7 хэрэгтэй, надад 3 л байна — бага зардалтай картыг сонгоё" гэж шийдвэр гаргасан. "Юу болсон + яах вэ" формат ажилласан.

Сайжруулалт 1 ([-1] мөр) хийсний дараа **Оюунааг** дахин 1 тоглоом тоглуулсан:
