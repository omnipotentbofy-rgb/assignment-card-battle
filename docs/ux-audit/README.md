## 3 гол сургамж

### 1. Emoji = Visual Shortcut
Текст-only terminal-д emoji нь "icon" үүрэг гүйцэтгэнэ. 💥 харвал шууд "attack", 💚 харвал "heal" гэдгийг 1 тоглоомын дараа ойлгодог. Энэ нь Сарнай персонад маш чухал — монгол текст уншихаас өмнө emoji-г харна.

### 2. "Юу болсон + яах вэ" Error формат
Анхны хувилбарт "Invalid input" гэж л бичсэн байсан. User test-ийн дараа "⚠️ 0–6 хооронд тоо оруулна уу" гэж өөрчилсөн. Хэрэглэгч юу буруу хийснээ + яах ёстойгоо нэг мөрөнд харна. Хэзээ ч зөвхөн "алдаа" гэж бичдэггүй.

### 3. Карт нэр = Брэнд, Систем мессеж = Хэрэглэгчийн хэл
Эхэндээ бүгдийг монголоор бичэх гэсэн. Гэвч "🔥 Галт бөмбөг" гэхэд Hearthstone тоглосон Түмэн "энэ юу вэ" гэсэн. Харин "Blazing Fireball" гэхэд шууд таньсан. Систем мессежийг бүгд монголоор үлдээснээр Сарнай ойлгоно, карт нэрийг англиар үлдээснээр Түмэн таньсан — хоёр персона хоёулаа сэтгэл хангалуун.
